Two defects found and fixed during this run (both in the harness run,
not papered over):
  1. get_sigflags() returns -1 for PDFs with no AcroForm at all; the
     first version treated any non-zero value as "signed" and flagged
     every plain PDF. Fixed: only a positive flag value counts.
  2. The signed-seed check required the literal bytes "/FT /Sig"
     (with a space); MuPDF writes "/FT/Sig". Fixed the check to the
     whitespace-tolerant /FT\s*/Sig pattern, matching the engine.
